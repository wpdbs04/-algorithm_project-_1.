### 2026.09.21 : (3주차 과제 진행) 텀프로젝트 진행 및 계획서 수정 작성. 
> 계획서 작성 후, HTML 기반 방식 알고리즘 시각화 사이트에 대한 기능 추가, 그래프 개선 및 문제점 확인 후,

> 계획서의 내용 변경 및 현실성 추가. 웹프로그래밍 1의 수업을 계기로 배웠던 HTML의 "NGINX" 프로그램을 활용하여 코드 설계 진행.

> 생성형 AI들을 각기 활용하여, 코드 설계 및 도움을 받아 프로젝트를 진행. 난수 생성기, 계층형 구조를 통한 점선 애니메이션 표들을 구현하는 
> 아이디어를 뽑아내어 프로젝트를 진행하였음.

### 2026.09.22 ~ 09.28 : "알고리즘 시각화 툴 사이트 프로젝트 진행 시작. 
> 사이트 기본 구조를 만들고 세팅하기 위해 생성형 AI의 힘을 통해, 도메인 특화 6대 레이아웃 구조를 설계

> 미등록 사이트 동적 생성기를 구현, 미리 정의되지 않은 수많은 생소한 URL 입력 후 "알고리즘 시각화" 진행 시, 도메인 해시값을 기반으로 3가지 아키텍쳐(Y-Sprit, StarCore, Serial Cascade) 중 하나를 
실시간 생성하는 기능을 추가하였음. 

> 그 후 HTML 코드를 통해 NGINX를 기반으로 사이트를 열어서 사용할 수 있도록 코드를 제작하였음.

### 2026.09.29 : HTML 사이트에서의 오류 및 개선 진행.
> 자바스크립트의 토큰 오류가 발생됨을 확인하여, 객체 내부 "delay" 구문 오타 수정을 AI를 통해 진행.

> 오류를 다시 확인하고 재수정하여 HTML 사이트 정상 접속을 확인하고, 디자인 개선을 시작하였음. 

> 디자인 업그레이드 초기를 위해, CSS 애니메이션 아이디어를 적용하고, 그라데이션 효과를 추가하여, 시각 효과를 추가해서, 보는 사람의 이해도를 올릴 수 있도록 개선하였음. 

### 2026.09.30 : 알고리즘 사이트 데이터 대량 추가, 서브 도메인 활용.
> "알고리즘 시각화" 진행 시, 각 기 수많은 사이트가 존재하기 때문에 거기에 맞게 알고리즘 정보가 정상적으로 뜰 수 있도록 데이터가 적용되어야 하지만, 코드에 넣은 알고리즘의 사이트 종류 데이터가 부족하여, 잘못된 내용이 보고되고 있음을 포착했음. 

> 결론, 사이트 데이터가 가장 부족하다는 것을 알게 되고, 알고리즘 사이트 데이터 추가를 위해, 다른 사이트에서 만들어진, 주소 모음집을 통해, 그 사이트에 있는 종류와 태그를 모아, 363개의 검증 사이트와 12개의 카테고리로 분류하여, 분석 데이터를 정리하고, 소스코드로 올려, AI LM 생성형으로 데이터를 적용하고, 코드를 완전 수정하는 작업을 거침. 

> 상단 UI 제어바 최적화, 서브 도메인 우선순위 정밀 파서 구축의 아이디어를 생성형 AI로 통해 추가. 

> 또한 시스템 구조도 및 표준을 이해할 수 있도록 미리 플로우차트 제작을 진행하였음.
